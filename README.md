## 📌 Project Overview

The **OTT Platforms Analysis Dashboard** is an interactive Power BI project designed to analyze and visualize content available across different OTT streaming platforms.

The dashboard provides insights into content distribution, platform availability, ratings, release years, content categories, and quality tiers. It helps users understand OTT content trends and compare the performance of different streaming platforms.

## 🎯 Project Objectives

- Analyze content distribution across different OTT platforms.
- Compare the availability of movies and TV shows.
- Understand content ratings and quality levels.
- Identify trends based on release years.
- Explore platform-wise content distribution and availability.

## 🛠️ Tools & Technologies

- **Power BI Desktop** – Dashboard development and visualization.
- **Power Query** – Data preparation and transformation.
- **Data Modeling** – Organizing content and platform-related data.

## 📊 Dashboard KPIs

The dashboard includes key performance indicators such as:

- Total Available Titles
- Total OTT Platforms
- Average Rotten Tomatoes Score
- Content Quality Index
- Platform-wise Content Counts

## 📈 Visualizations

The dashboard includes the following visualizations:

- **Platform-wise Content Analysis:** Compares content distribution across OTT platforms.
- **Content Type Analysis:** Analyzes the distribution of movies and TV shows.
- **Release Year Analysis:** Shows content trends based on release years.
- **Content Rating Analysis:** Examines Rotten Tomatoes rating bands.
- **Age Category Analysis:** Displays content distribution by age category.
- **Quality Tier Analysis:** Compares content across different quality tiers.
- **Top 10 Titles:** Displays top-rated titles with their quality tier, available platforms, Rotten Tomatoes scores, release years, and age categories.
- **Platform Availability:** Compares the number of available titles across platforms.

## 🎛️ Interactive Filters

The dashboard provides interactive slicers to explore the data:

- Year
- Platform Name

These filters allow users to analyze specific years and OTT platforms.

## 💡 Key Insights

The dashboard helps users:

- Compare content availability across OTT platforms.
- Identify popular content categories.
- Understand the distribution of content ratings.
- Explore historical content release trends.
- Evaluate content quality using Rotten Tomatoes scores.
- Identify top-rated titles.
